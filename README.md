# Little Swiggles

A playful storefront for children’s clothing and accessories.

## Features

- Product listings with image galleries
- Product category filters
- Shopping cart and wishlist
- Featured image carousel
- Product detail pages

## Project files

- `index.html` — storefront page
- `product.html` — product detail pages
- `images/` — product, logo, and carousel images
- `styles.css` and `script.js` — additional CSS and JavaScript files

## Publishing

This site can be published with GitHub Pages. Keep `index.html` at the published site’s root and include the `images/` folder in the repository.

Image paths and filenames are case-sensitive. For example, `images/Logo.jpg` and `images/logo.jpg` are different paths.

## Note

The cart and wishlist are temporary: their contents reset when the page is refreshed. Checkout is not connected to a payment service.
